# Section Prompt: Executive Summary

Write a 2-paragraph executive summary for a Credit Approval Memorandum.

## Paragraph 1 — Company Overview
- Company name, sector, incorporation year, registered state
- Listed/unlisted status, credit rating (agency + grade + outlook)
- Business description, scale of operations
- Management quality and governance assessment

## Paragraph 2 — Facility Request & Recommendation
- Facility type, amount requested (₹ Cr), purpose
- Recommended action: **APPROVE** / **CONDITIONAL APPROVE** / **REFER** / **DECLINE**
- Risk grade and composite score breakdown
- Key credit strengths (top 3)
- Key concerns/risks (top 3)

## Summary Metrics Table
Include a table with these columns:
| Parameter | Value |
| Company Name | ... |
| Facility Requested | Type — ₹ X Cr |
| Credit Rating | Agency: Grade (Outlook) |
| Revenue (Latest) | ₹ X Cr |
| EBITDA (Latest) | ₹ X Cr (Margin %) |
| Net Worth | ₹ X Cr |
| Total Debt | ₹ X Cr |
| Risk Grade | Grade (Score: X/100) |
| Recommendation | APPROVE/DECLINE |

## Data Keys
`case_summary`, `borrower_profile`, `financial_summary`, `policy_decisions`,
`credit_strengths`, `key_risks`

## Word Count Target
200–300 words
